# Installation

## Requirements

- Python **3.11** or later
- [pip](https://pip.pypa.io) or [Poetry](https://python-poetry.org)

## Via pip

```bash
pip install mkdocs-theme-rabe
```

## Via Poetry

```bash
poetry add mkdocs-theme-rabe
```

This will also install MkDocs, MkDocs-Material, `mkdocstrings`, and all
other bundled dependencies automatically – you do **not** need to list them
separately.
